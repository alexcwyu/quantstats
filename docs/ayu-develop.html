Design decisions

Decision Rationale Tradeoff Evidence
Use functions operating on supplied return series. Analytics can be applied to results from different trading engines. Metric validity depends on return preparation, calendar and annualization assumptions. metrics (L1193) / sharpe (L938)
Monte Carlo permutes realized historical returns. Examines path-order outcomes while retaining the sample values. Permutation does not model a new market-generating process. run_montecarlo (L218)

Strengths and limits

Strengths

  • Reports and standalone statistics share the same return analytics functions. html (L206) / metrics (L1193) / sharpe (L938)

Limitations

  • Normal VaR assumes a parametric distribution and is not a trading risk limiter. value_at_risk (L2014)
  • The downloader depends on Yahoo Finance availability and adjustments. download_returns (L758)
